Задача: "Создание и управление ветками"

Создание новой ветки: В существующем локальном репозитории создайте новую ветку для разработки новой функциональности, например, с именем feature/new-feature. Используйте команду git branch для создания ветки.

СДЕЛАНО

Переключение на новую ветку: Переключитесь на созданную ветку с помощью команды git checkout.

СДЕЛАНО

Убедитесь, что вы работаете в этой ветке.

НУ Я ПИСАЛА ГИТ СТАТУС, ВРОДЕ НА НУЖНОЙ ВЕТКЕ

Внесение изменений: Внесите изменения в код или текстовый файл. Это могут быть новые функции, исправления или просто добавление комментариев.

НУ ВОТ НАПИСАЛА ВСЯКОГО

Создание и переключение ветки одновременно: Создайте ещё одну ветку, назвав её feature/another-feature, и одновременно переключитесь на неё, используя команду git checkout -b.

Коммит изменений: После внесения изменений добавьте их в индекс и создайте коммит с подробным описанием внесённых изменений.

Просмотр веток: Проверьте список всех веток в репозитории, используя команду git branch, и убедитесь, что все созданные ветки отображаются.

Удаление веток: Удалите локальную ветку feature/new-feature, если она больше не нужна, с помощью команды git push origin --delete <имя-ветки>.
